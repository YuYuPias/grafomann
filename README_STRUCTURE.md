# GRAFOMANN — PROJECT STRUCTURE

GrafoMann — статический сайт на GitHub Pages.

Основной адрес:
https://yuyupias.github.io/grafomann/


## Корень проекта

- `index.html` — главная страница сайта.
- `_templates/` — канонические шаблоны публикаций.
- `about/` — страница «О сайте».
- `contacts/` — контакты.
- `drafts/` — рабочие материалы и черновики.
- `france/` — публикации о Франции.
- `italy/` — публикации об Италии.
- `spain/` — публикации об Испании.
- `uk/` — публикации о Великобритании.
- `texts/` — раздел «Вне маршрута». Имя папки историческое и не меняется.
- `css/` — все стили сайта.
- `js/` — общие JavaScript-модули.


## CSS

- `main.css` — общая оболочка сайта: body, базовая типографика, навигация и общие элементы.
- `home.css` — только главная страница.
- `info.css` — служебные страницы «О сайте» и «Контакты».
- `articles.css` — структура и типографика публикаций.
- `gallery.css` — визуальный словарь галерей, компоновки и crop-позиционирование.
- `lightbox.css` — оформление кинозала / lightbox.
- `sections.css` — страницы разделов.
- `texts.css` — специальные стили публикаций раздела «Вне маршрута».


## JavaScript

- `lightbox.js` — единый просмотрщик изображений: открытие фотографий, навигация, zoom, перетаскивание и мобильные жесты.


## Документация проекта

- `README.md` — краткое описание проекта и точка входа в документацию.
- `README_STRUCTURE.md` — структура проекта и распределение функций между файлами.
- `README_STYLE.md` — визуальные и типографические принципы сайта.
- `README_GALLERY.md` — система галерей, композиционные модули, кадрирование и мобильное поведение.

При изменении архитектуры сайта соответствующая документация должна обновляться вместе с кодом.

## Шаблоны публикаций

Канонические шаблоны находятся в папке `_templates/`.

- `template.html` — обычная статья или эссе на основе `.post wide`;
- `story.html` — прозаический литературный текст на основе `.story`;
- `poetry-essay.html` — публикация, соединяющая стихотворный текст и анализ, на основе `.poetry-essay`.

Шаблоны отличаются прежде всего характером верстки текста.

При этом все типы публикаций могут использовать общие возможности сайта:
галереи из `gallery.css`, lightbox, навигацию и мобильные жесты.

Новая публикация создаётся на основе ближайшего по типу шаблона.

Шаблоны должны оставаться актуальными и служат главным образцом HTML-структуры новых страниц.


## Принцип

Каждая новая публикация собирается из существующих модулей.

Новые CSS-классы создаются только тогда, когда появляется новая функция, а не новая статья.

Оформление не добавляется в отдельные HTML-страницы через `<style>`, если его можно реализовать существующим или новым общим CSS-модулем.

Изменение общего класса не должно ломать уже опубликованные страницы. Для частных случаев используются дополнительные классы-модификаторы.
