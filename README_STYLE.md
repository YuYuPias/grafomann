# GRAFOMANN — STYLE GUIDE

ГрафоМанн — не блог и не фотогалерея.

Текст и изображение образуют единое повествование.
Фотографии являются частью текста, а верстка — частью языка проекта.


## Общий визуальный принцип

Сайт должен оставаться спокойным и нейтральным.

Интерфейс не должен конкурировать с текстом и фотографиями.

Основной фон сайта — теплый светлый:
`#f7f4ef`

Основной текст — темный нейтральный.

Дополнительные элементы, даты и навигация — серые и визуально второстепенные.

Декоративные эффекты, рамки, тени и активная графика используются только тогда, когда имеют функциональный смысл.


## Типографика

Основной шрифт сайта — системный sans-serif:

`Helvetica, Arial, sans-serif`

Главный заголовок публикации — `h1`.

Для дополнительного подзаголовка используется:

`.subtitle`

Для внутренних глав длинного текста:

`.chapter-title`

Дата публикации:

`.date`

Типографическая иерархия должна строиться размером, интервалами и насыщенностью, а не декоративными эффектами.


## Ширина публикаций

Основной тип публикации:

`.post`

Для публикаций, в которых важную роль играют крупные изображения:

`.post.wide`

Ширина текста и изображений должна оставаться согласованной внутри всей публикации.


## Фотографии

Фотографии не являются украшением страницы.

Они могут:

- продолжать мысль текста;
- создавать паузу;
- работать как последовательность;
- показывать объект аналитически;
- создавать самостоятельный визуальный блок.

Для компоновки изображений используются только общие классы из `gallery.css`.

Правила галерей подробно описаны в:

`README_GALLERY.md`


## Мобильная версия

Мобильная версия является полноценной версией сайта, а не уменьшенной копией desktop.

Текст должен оставаться легко читаемым.

Галереи могут перестраиваться на мобильном экране, если этого требует композиция.

Изображения не должны произвольно обрезаться или менять смысл композиции.

Кинозал должен поддерживать удобную навигацию и масштабирование на сенсорном экране.


## Общие модули публикаций

### post

Основной контейнер обычной статьи или эссе.

### post wide

Публикация, использующая широкую визуальную композицию.

### article-intro

Вступительный блок обзорной статьи.

### catalog-item

Самостоятельный объект внутри обзорной статьи.

Может использоваться для станции метро, моста, памятника, здания, двери или другого рассматриваемого объекта.

### item-title

Название объекта внутри `catalog-item`.

### item-meta

Краткие паспортные сведения об объекте:
адрес, автор, дата, стиль и другие данные.

### gallery-note

Пояснение к фотографии или серии фотографий.


## CSS

Оформление сайта хранится во внешних CSS-файлах.

Не следует добавлять `<style>` в отдельную публикацию для решения локальной задачи, если её можно решить существующим классом или общим модификатором.

Если требуется новое визуальное поведение:

1. сначала проверяется существующая система классов;
2. затем при необходимости создаётся новый универсальный класс;
3. класс называется по функции, а не по названию конкретной статьи.

Локальный `<style>` внутри отдельной публикации допустим только как временное
решение во время настройки страницы.

Если найденное оформление может использоваться повторно, оно переносится
в соответствующий общий CSS-файл.

## Совместимость

Существующие общие классы нельзя менять так, чтобы это нарушало уже опубликованные страницы.

Если одной публикации требуется исключение, предпочтительно создать дополнительный класс-модификатор, а не менять базовое правило.


## Главный принцип

Названия модулей описывают функцию, а не конкретную публикацию.

Новая статья должна использовать существующий визуальный язык сайта, а не создавать собственную систему оформления.

## Литературные публикации

### story

Основной контейнер для прозаических литературных текстов.

```html
<article class="story">
```
Верстка `story` рассчитана на длительное чтение и отличается от обычных
иллюстрированных статей более узкой колонкой и более плотным ритмом текста.

Основной принцип:

- обычные абзацы имеют плотную межстрочную верстку;
- расстояние между абзацами небольшое;
- текст воспринимается как непрерывное повествование, а не как набор отдельных блоков.

### dialogue

Используется для последовательных реплик диалога внутри `story`.

```html
<p class="dialogue">— Реплика.</p>
```

### chapter

Разделитель частей литературного текста.
Используется для нумерованных частей, звездочек и других внутренних пауз.

```html
<div class="chapter">2.</div>
```

или:

```html
<div class="chapter">***</div>
```

`chapter` не является заголовком в обычном смысле. Его задача — обозначить
переход между частями текста и создать визуальную паузу внутри повествования.

### poetry-essay

Основной контейнер для публикаций, в которых стихотворный текст соединён
с авторским комментарием и анализом.

```html
<main class="poetry-essay">
```

Внутри `poetry-essay` используются несколько самостоятельных модулей:

- `poem` — стихотворный фрагмент;
- `epigraph` — эпиграф;
- `analysis-block` — отдельный смысловой блок комментария;
- `analysis-title` — небольшой заголовок внутри аналитического блока.

Верстка `poetry-essay` сохраняет более свободный ритм, чем `story`:
стихотворение визуально отделяется от прозы, а аналитические блоки образуют
последовательность самостоятельных смысловых фрагментов.

### poem

Стихотворный фрагмент внутри `poetry-essay`.

```html
<div class="poem">
    Первая строка,<br>
    вторая строка,<br>
    третья строка.
</div>
```

`poem` визуально отделяет стихотворение от авторской прозы и сохраняет
его собственный ритм.

Для переноса стихотворных строк используется `<br>`, а не отдельные абзацы.

### epigraph

Короткий эпиграф или цитата перед основным текстом или отдельным смысловым блоком.

```html
<div class="epigraph">
    Текст эпиграфа
</div>
```

`epigraph` выравнивается вправо, имеет меньший размер шрифта и курсивное
начертание.

Используется как вводная интонация, а не как обычный абзац текста.

### analysis-block

Самостоятельный смысловой блок комментария внутри `poetry-essay`.

```html
<div class="analysis-block">
    <p>Текст комментария.</p>
</div>
```

`analysis-block` объединяет несколько связанных абзацев в один аналитический
фрагмент и задаёт между такими фрагментами устойчивую визуальную паузу.

Используется не для каждого абзаца, а только там, где начинается новый
смысловой шаг анализа.

### analysis-title

Небольшой внутренний заголовок внутри `analysis-block`.

```html
<div class="analysis-title">
    Название смыслового фрагмента
</div>
```

`analysis-title` используется для мягкого смыслового акцента внутри анализа.

Он не должен конкурировать с основным заголовком публикации: поэтому имеет
обычный вес, курсивное начертание и сравнительно небольшой размер.
