# GRAFOMANN — GALLERY GUIDE

Фотографии в ГрафоМанне не иллюстрируют текст. Они являются его абзацами.

Галерея — это композиционный модуль страницы.  
CSS определяет форму композиции, а роль фотографии определяется её местом
в повествовании.

Все галереи строятся на базовом классе `gallery`.

```html
<div class="gallery">
    ...
</div>
```

К нему добавляется класс, определяющий тип композиции, и при необходимости
дополнительные модификаторы ширины, ориентации, кадрирования или мобильного
поведения.

## Основные модули

### single

Одна самостоятельная фотография.

```html
<div class="gallery single">
    <a href="image.jpg">
        <img src="image.jpg" alt="">
    </a>
</div>
```

### diptych

Две фотографии, образующие единую композицию.

```html
<div class="gallery diptych">
    ...
</div>
```

### triptych

Три фотографии в один ряд.

```html
<div class="gallery triptych">
    ...
</div>
```

### quartet

Четыре фотографии в один ряд.

```html
<div class="gallery quartet">
    ...
</div>
```

### contact-sheet

Компактная сетка из трёх колонок.

```html
<div class="gallery contact-sheet">
    ...
</div>
```

### stamp-sheet

Плотная сетка небольших изображений.

На большом экране — шесть колонок.

```html
<div class="gallery stamp-sheet">
    ...
</div>
```


## Варианты показа и ориентации

### cropped

Используется для одиночной фотографии с принудительным кадрированием
в пропорции 16:9.

```html
<div class="gallery single cropped">
    ...
</div>
```

Изображение заполняет весь блок через `object-fit: cover`.

### contain

Используется для `diptych`, когда обе фотографии должны быть показаны полностью
без принудительного кадрирования.

```html
<div class="gallery diptych contain">
    ...
</div>
```

### hh

Две горизонтальные фотографии.

```html
<div class="gallery diptych hh">
    ...
</div>
```

Фотографии показываются полностью, без фиксированной высоты.

### vv

Две вертикальные фотографии.

```html
<div class="gallery diptych vv">
    ...
</div>
```

Фотографии показываются полностью, без фиксированной высоты.

### hv

Слева горизонтальная фотография, справа вертикальная.

```html
<div class="gallery diptych hv">
    ...
</div>
```

На большом экране левая колонка шире правой.

### vh

Слева вертикальная фотография, справа горизонтальная.

```html
<div class="gallery diptych vh">
    ...
</div>
```

На большом экране правая колонка шире левой.

Для `hv` и `vh` на большом экране изображения выравниваются по общей высоте
и кадрируются через `object-fit: cover`.


## Модификаторы ширины

### small

Очень узкий визуальный блок.

```html
<div class="gallery single small">
    ...
</div>
```

Максимальная ширина:

- большой экран — 460 px;
- телефон — 320 px.

### narrow

Узкая галерея.

```html
<div class="gallery narrow">
    ...
</div>
```

Максимальная ширина — 620 px.

### medium

Средняя ширина.

```html
<div class="gallery medium">
    ...
</div>
```

Максимальная ширина — 800 px.

### wide

Широкая галерея.

```html
<div class="gallery wide">
    ...
</div>
```

Максимальная ширина — 1000 px.

Внутри `.post.wide` одиночная фотография `.gallery.single` также может
занимать до 1000 px.

На экранах шириной до 800 px включительно для `single`, `diptych` и
`contact-sheet` задано `max-width: 100%`, которое переопределяет обычные
модификаторы `narrow`, `medium` и `wide`. Модификатор `small` сохраняет
ограничение 320 px. Более специфичные правила для `single cropped` и
`.post.wide .gallery.single` сохраняют своё ограничение 1000 px.


## Модификаторы кадрирования

Модификаторы `crop-*` управляют тем, какая часть изображения остаётся в кадре,
когда фотография показывается через `object-fit: cover`.

Модификатор можно поставить на отдельную ссылку `<a>`, если нужно изменить
кадрирование одной фотографии, или на контейнер `.gallery`, если одинаковое
кадрирование требуется всей композиции.

Исключение в текущем CSS — `single cropped`: более специфичное правило
`.gallery.single.cropped img` задаёт `object-position: center center`
и перекрывает перечисленные модификаторы `crop-*`.

```html
<div class="gallery diptych">
    <a class="crop-top" href="image.jpg">
        <img src="image.jpg" alt="">
    </a>
</div>
```

### crop-top

Показывает верхнюю часть изображения.

```html
<a class="crop-top" href="image.jpg">
```

### crop-bottom

Показывает нижнюю часть изображения.

```html
<a class="crop-bottom" href="image.jpg">
```

### crop-left

Смещает кадрирование к левому краю.

```html
<a class="crop-left" href="image.jpg">
```

### crop-right

Смещает кадрирование к правому краю.

```html
<a class="crop-right" href="image.jpg">
```

### Точное вертикальное кадрирование

Для более тонкой настройки используются промежуточные вертикальные позиции:

- `crop-y-20`
- `crop-y-30`
- `crop-y-40`
- `crop-y-60`
- `crop-y-70`
- `crop-y-80`

Например:

```html
<a class="crop-y-30" href="image.jpg">
    <img src="image.jpg" alt="">
</a>
```

Число обозначает вертикальную позицию изображения внутри кадра:

- меньшее значение показывает область ближе к верхнему краю фотографии;
- большее значение показывает область ближе к нижнему краю фотографии;
- 50% соответствует центрированию по вертикали.

Эти модификаторы используются только там, где изображение действительно
кадрируется через `object-fit: cover`.


## Мобильное поведение

На экранах шириной до 800 px включительно галереи адаптируются по-разному в зависимости от их
композиционной задачи.

### diptych

Обычный `diptych` сохраняет две колонки.

```html
<div class="gallery diptych">
    ...
</div>
```

### triptych

`triptych` сохраняет три колонки и на телефоне.

### hv и vh

Смешанные пары `hv` и `vh` на телефоне переходят в одну колонку.

Фиксированная высота снимается, изображения показываются с естественными
пропорциями.

### mobile-pair

Если пару необходимо сохранить именно рядом и на телефоне, используется
модификатор `mobile-pair`.

```html
<div class="gallery diptych mobile-pair">
    ...
</div>
```

На телефоне такая галерея остаётся двухколоночной.

Изображения получают вертикальную пропорцию 2:3 и кадрируются через
`object-fit: cover`.

### quartet

`quartet` на телефоне превращается из четырёх колонок в две.

### contact-sheet

`contact-sheet` сохраняет три колонки.

Высота изображения уменьшается до 120 px.

### stamp-sheet

`stamp-sheet` на телефоне переходит с шести колонок на три.


## Дополнительные модификаторы

### tall

Используется вместе с `quartet`, если изображения должны быть заметно выше
обычной четверки.

```html
<div class="gallery quartet tall">
    ...
</div>
```

На большом экране высота изображений — 220 px.

На телефоне `quartet tall` остаётся двухколоночным, а высота изображений
уменьшается до 180 px.

### separate

Используется для визуального блока, который должен быть сильнее отделён
от предыдущего текста или галереи.

```html
<div class="gallery single separate">
    ...
</div>
```

Модификатор увеличивает верхний отступ:

- 80 px на большом экране;
- 70 px на телефоне.
