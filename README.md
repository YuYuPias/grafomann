# GRAFOMANN

ГрафоМанн — авторский проект о встрече с местом, вещью или событием и о том,
как письмо превращает впечатление в часть личной биографии.

Текст и фотография здесь обладают равным статусом.
Фотографии не иллюстрируют рассказ — они являются частью повествования.

Сайт объединяет прогулки, наблюдения, архитектуру, городские и загородные
места, случайные находки и литературные тексты.

Живой сайт:

https://yuyupias.github.io/grafomann/

## Основные принципы

- Новые CSS-классы создаются только тогда, когда появляется новая функция.
- Названия классов описывают функцию, а не конкретную публикацию.
- Новая страница по возможности собирается из уже существующих модулей.
- Общие правила не изменяются так, чтобы ломать уже опубликованные страницы.
- Текст, фотография и верстка являются частями одного повествования.
- Простота важнее эффектности.
